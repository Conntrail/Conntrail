Conntrail tells you why your agent decided what it decided — and how close it was to deciding something else.

Most tracing tools record what happened. Conntrail measures how brittle the decision was: whether a paraphrase, a tone change, or a semantic inversion of the same input would have sent the agent down a different route — and which dimension flipped it first.

How it works

      
    
        
  1. Your node runs normally — output is unchanged.
    2. 
        
  2. A cheap model (never your agent's model) generates three perturbed variants of the input: similar, neutral, opposite.
    3. 
        
  3. Conntrail re-runs the node on all four inputs and computes normalized Shannon entropy over the routing outcomes: 0.0 = never flips, 1.0 = maximally unstable.
    4. 
        
  4. A fixed priority table names which dimension flipped the route first (opposite > neutral > similar) and the counterfactual route.
